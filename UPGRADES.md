# Upgrades

## 0.32.0

Breaking.

- protos 0.32.0: `textualize` of a projected datom writes the vertical
  canonical print, and a projected tree carries that print's extents (protos
  assigns them; this crate no longer measures a one-line layout). A consumer
  asserting a one-line reply of a nested datom updates the expectation or calls
  `protos::Compactable::compact`.
- The helper kinds are renamed to the kinds `datom-codec-kinds.ethos` names
  them: `Pathing` is `Branchable`, `Budgeting` is `Budgeted`, `Positioning` is
  `Positional`. A consumer importing one of them by name renames the import;
  code generated by the derives needs nothing, since the derive emits the new
  names.

To deploy: repin datom-codec (and protos to the same revision it pins), rename
any import above, run the consumer's tests, and update or compact any one-line
expected text.
